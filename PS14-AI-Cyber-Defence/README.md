# PS14 — AI Cyber Defence for Military Networks

## Objective

AI-assisted defensive cyber-security platform capable of
detecting, correlating, analysing and responding to
multi-stage cyber attacks.

## Core Pipeline

Telemetry
→ Normalization
→ Detection
→ Correlation
→ Attack Progression
→ Risk Assessment
→ Prediction
→ Intervention
